# Better Lyrics Bar v1.1.0

Better Lyrics Bar v1.1.0 brings enhanced playback controls, improved word-by-word lyric visual contrast, restored width preferences with jitter protection, and repository alignment for GNOME Shell 46–50.

## Highlights

- **Accurate Lyric Line Seeking**: Clicking any line in the interactive details menu now seeks directly to the target timestamp using standard MPRIS `SetPosition` for browser players (Firefox, Chromium) and adaptive offset seeking for Spotify Desktop, resolving the 5-second rewind defect.
- **Enhanced Word-by-Word Lyrics Highlight**: Upgraded word-level synchronization to use solid Rec. 601 luma dimming and bold active text. Eliminates diffuse glow washout and provides proper dimmed preview during song intros.
- **Restored Width Preferences & Jitter Guard**: Re-added "Auto width" and "Manual width" settings to Preferences. Word-by-word 40ms updates are safely decoupled when auto width is active to prevent GNOME Shell panel layout jitter.
- **Blur my Shell Compatibility**: Native background styling support for translucent top-bar panels using the Blur my Shell extension.
- **Repository Alignment & Installer Updates**: Standardized repository and asset URLs to `furkansa50/bettergnome-lyricsbar`, aligned GPL-3.0 package licensing, and updated automated installation and updater scripts.

# Better Lyrics Bar v1.0.0

Initial major release of Better Lyrics Bar for GNOME Shell 46–50.

## Highlights

- **Word-by-Word Live Lyrics**: Real-time word-level synchronization with smooth transitions and glow highlighting.
- **Multi-Provider Pipeline**: Intelligent lyric lookup across Musixmatch (RichSync and LRC), Better Lyrics API, and LRCLIB with local caching.
- **Dynamic Auto-Width**: Top-bar indicator automatically adapts its width to fit current lyrics without awkward padding or truncation.
- **Interactive Song Details Menu**: Top-bar popup featuring track metadata, playback controls (Play/Pause, Next, Previous), progress/seek slider, volume control, and active lyrics source switcher.
- **Deep MPRIS Integration**: Out-of-the-box support for Spotify Desktop, Spotify Web, YouTube Music Web, Apple Music Web, and standard MPRIS players.
- **Appearance Customization**: Configurable text color (presets or custom HEX), drop shadows, glow strength, text alignment, and panel positioning.
- **Strict Architecture**: Robust lifecycle cleanup, guarded async callbacks, and isolated pure domain logic.

## Verification

- `npm run verify` passing all 506 unit tests, schema validation, architecture guardrails, and extension bundle packaging.
- `npm audit` passing with 0 vulnerabilities.
- Verified on GNOME Shell 46–50 environments.

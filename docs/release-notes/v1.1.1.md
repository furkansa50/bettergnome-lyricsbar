# Better Lyrics Bar v1.1.1

Better Lyrics Bar v1.1.1 introduces interactive in-player lyrics synchronization offset controls, cold-start latency elimination with session token pre-warming, and persistent token caching for instant lyric lookups.

## Highlights

- **In-Player Real-Time Sync Offset**: Directly adjust lyric timing (`±50ms` increments) from the player popup menu without opening Preferences. Includes an active offset pill badge with one-click reset to `0ms`.
- **Cold-Start Elimination**: The Musixmatch anonymous session token is now pre-warmed asynchronously upon extension startup, eliminating the 1.5–3 second latency when playing a track for the first time.
- **Disk Token Persistence**: Session tokens are automatically persisted to `~/.cache/lyricbar/musixmatch-token.json`, enabling `0ms` instant lookups across desktop logins and shell restarts. Expired tokens (HTTP 401) are automatically refreshed.
- **Faster Provider Fallback**: Lowered provider timeouts from 10s to 5s, ensuring degraded upstream APIs fall back to secondary providers (Better Lyrics and LRCLIB) twice as fast.
- **Preferences Sync Offset**: Added a dedicated `Adw.SpinRow` under **Behavior** in the Preferences window for precise lyric timing adjustment between -5000ms and +5000ms.
